# 知其所以 · 经济金融保险基础

面向经济、金融与保险基础知识的分章互动学习网站，覆盖 **经济基础（17 章）**、**金融基础（8 章）**、**保险基础（6 章）** 共 31 章内容。

- 项目仓库：[https://github.com/XWalways/zhiqi-finance-study](https://github.com/XWalways/zhiqi-finance-study)

## 主要特性

- **章首思维导图**：每章开头即展示可缩放、可展开/收起的树状知识导图，点击任意节点直达对应讲解。
- **图文结合考点精讲**：系统梳理核心概念、高频考点、生活例子与易错提醒，并将交互式图解（如生产可能性曲线、供需与市场均衡）直接嵌入对应知识点，边读边调参数。
- **即学即练 + 整章测试**：每个知识点讲解后紧跟配套练习题，随时核对答案与逐项解析；同时保留整章逐题练习、本章测试与错题复习模式。
- **单文件离线学习**：每一章均提供独立离线 HTML 文件，下载后断网双击浏览器即可完整阅读、交互与答题。
- **深色 / 跟随系统 / 浅色外观**：右上角三态图标按钮一键切换主题，并自动记住偏好。
- **本地记录与备份**：阅读进度、收藏与错题本按章节保存在当前浏览器，支持 JSON 备份导出与跨设备恢复。

## 目录结构

- `index.html`：学习目录首页
- `chapter01.html` ~ `chapter31.html`：在线分章学习页面
- `*-离线学习.html`：各章单文件离线学习版
- `catalog.js`：章节目录配置脚本
